什么是 CSS 变量

以 -- 前缀声明，通过 var() 引用。 本页所有颜色、圆角、阴影、间距均来自 :root 中的变量定义。

作用域与继承

定义在 :root 上的变量对整个文档生效；定义在某个选择器内部的变量只在该元素及其子元素中生效，体现 CSS 的继承特性。

var() 回退值

当变量未定义时，可使用第二个参数作为回退值。下方色块引用了不存在的 --undefined-color，因此显示回退颜色：

var(--undefined-color, orange)

动态切换主题

点击上方按钮，通过给 <body> 添加 theme-light 类覆盖同名变量，即可整站换肤，无需逐条修改样式。

变量参与计算

变量可以参与 calc() 计算，例如本卡片圆角使用 calc(var(--radius) / 2)，间距统一由 var(--spacing) 管理。
